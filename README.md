# Varma Tech – Cloud & DevOps Website

A modern responsive website showcasing Cloud, DevOps, and Automation solutions.

## 🚀 Project Overview

This project demonstrates a complete DevOps workflow where a website is developed, version-controlled using GitHub, continuously built using Azure DevOps Pipelines, and deployed automatically to GitHub Pages.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Azure DevOps
- CI/CD Pipelines
- GitHub Pages
- Docker

## 🔄 CI/CD Workflow

```text
Developer
   ↓
GitHub Repository
   ↓
Azure DevOps Pipeline
   ↓
Build & Validate
   ↓
Package Website
   ↓
Deploy to GitHub Pages
   ↓
Live Website

DEVOPS IMPLEMENTION:
Source code maintained in GitHub
Azure DevOps YAML pipeline configured
Automated website validation
Website files packaged as an artifact
Automated deployment to GitHub Pages
GitHub Personal Access Token stored securely as an Azure DevOps secret variable
